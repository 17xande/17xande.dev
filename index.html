About this site

This site was created the traditional old fashioned way. Made lovingly, by hand.

That's right, no frameworks were harmed in the making of this website. It was just NeoVim and me (I use NeoVim by the way), crafting HTML tags and refreshing my browser. This is a classic, all natural, home-made, free-range, organic, grass-fed website, with no preservatives, atificial ingredients, or artificial intelligence.

Just one HTML, one CSS and one JavaScript file.

I could have embedded the CSS and JavaScript in the HTML file, but as a wise man once said:

Everything should be made as simple as possible, but not simpler.
